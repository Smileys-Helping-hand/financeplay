🗄️  STEP 1: DATABASE (5 min)
══════════════════════════════════════════════════════════════════════
Choose one:
┌──────────────────────────────────────────────────────────────────┐
│ Supabase: https://supabase.com (Recommended)                    │
│ Neon:     https://neon.tech                                      │
└──────────────────────────────────────────────────────────────────┘

Copy your connection string:
postgresql://user:password@host.com:5432/database

══════════════════════════════════════════════════════════════════════

🔧 STEP 2: BACKEND DEPLOYMENT (10 min)
══════════════════════════════════════════════════════════════════════
URL: https://vercel.com/new

┌──────────────────────────────────────────────────────────────────┐
│ Configuration:                                                   │
│ • Root Directory: backend                                        │
│ • Build Command:  npm run vercel-build                           │
└──────────────────────────────────────────────────────────────────┘

Environment Variables to Add:
┌──────────────────────────────────────────────────────────────────┐
│ DATABASE_URL=postgresql://[from Step 1]                          │
│ OPENAI_API_KEY=your-openai-api-key-here             │
│ PORT=4002                                                        │
│ NODE_ENV=production                                              │
└──────────────────────────────────────────────────────────────────┘

After deployment, COPY your backend URL:
https://financeplay-backend.vercel.app

══════════════════════════════════════════════════════════════════════

🎨 STEP 3: FRONTEND DEPLOYMENT (10 min)
══════════════════════════════════════════════════════════════════════
URL: https://vercel.com/new (import SAME repo again)

┌──────────────────────────────────────────────────────────────────┐
│ Configuration:                                                   │
│ • Root Directory: frontend                                       │
│ • Framework:      Next.js (auto-detected)                        │
└──────────────────────────────────────────────────────────────────┘

Environment Variables to Add:
┌──────────────────────────────────────────────────────────────────┐
│ NEXT_PUBLIC_API_URL=[YOUR BACKEND URL FROM STEP 2]               │
│ DATABASE_URL=postgresql://[same as Step 1]                       │
└──────────────────────────────────────────────────────────────────┘

After deployment, COPY your frontend URL:
https://financeplay.vercel.app
